驱动基础

发表于 2025-07-20 更新于 2025-08-31

一个 Linux 驱动程序必须包含以下核心模块，这些模块构成了驱动程序的基础框架和功能实现：

一、头文件

  • 必须包含：<linux/module.h> 和 <linux/init.h>
    • module.h 提供了模块加载/卸载相关的宏定义（如 module_init、module_exit）。
    • init.h 定义了模块初始化和退出函数的声明方式。
  • 其他常用头文件：
    • <linux/fs.h>（文件操作接口）
    • <linux/kernel.h>（内核通用函数）
    • <linux/cdev.h>（字符设备操作）。

二、模块加载与卸载函数

  • 初始化函数（module_init 注册）：
    • 驱动加载时自动执行，用于注册设备、分配资源（如内存、中断号）、初始化硬件等。
    • 示例函数名：hi_driver_init。
  • 退出函数（module_exit 注册）：
    • 驱动卸载时自动执行，用于释放资源、注销设备、关闭中断等。
    • 示例函数名：hi_driver_exit。

三、许可证声明

  • 必须声明：通过 MODULE_LICENSE("GPL") 指定驱动的许可证类型（如 GPL、MIT等）。
    • 若未声明，内核会加载非标准模块并警告。
  • 其他可选声明：
    • MODULE_AUTHOR（作者信息）
    • MODULE_VERSION（版本号）
    • MODULE_DESCRIPTION（功能描述）。

四、设备注册与注销

  • 字符设备注册：
    • 使用 register_chrdev() 注册字符设备，需定义主设备号和次设备号。
    • 示例：register_chrdev(major, "my_device", &fops)。
  • 设备注销：
    • 使用 unregister_chrdev() 释放设备号。
  • 设备类与设备节点：
    • 通过 class_create() 和 device_create() 创建设备类和节点（现代内核推荐方式）。

五、文件操作结构体（file_operations）

  • 必须实现：定义用户空间与驱动交互的接口函数，如：
    • open（设备打开）
    • read/write（数据读写）
    • ioctl（控制命令）
    • release（设备关闭）。

六、中断处理（可选但常见）

  • 中断注册：通过 request_irq() 注册中断服务例程（ISR），处理硬件中断事件。
  • 中断释放：使用 free_irq() 释放中断资源。

七、内存管理

  • 内核内存分配：使用 kmalloc() 和 kfree() 分配/释放内核内存。
  • 物理地址映射：通过 ioremap() 将物理地址映射到内核虚拟地址空间。
